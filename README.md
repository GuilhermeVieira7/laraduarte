# Lara Duarte · Estética e Epilação — site

Site da **Lara Duarte Estética e Epilação** (Rua L, Nº 153, Bairro União, Parauapebas/PA).
Estático (HTML + CSS + JS puro), pronto pra Vercel sem build.

- Serviços com preço e duração (objeto `SERVICOS` em `script.js`: preencha `preco` e `dur`; sem preço aparece "Valor sob consulta")
- Depoimentos: array `DEPOIMENTOS` em `script.js` (a seção só aparece quando houver depoimentos reais)
- Barra fixa de agendamento no celular + bandeja que monta a mensagem no WhatsApp
- Quiz "Você sabe do que a sua pele precisa?" que sugere cuidados
- Tour em vídeo do espaço, relógio "Hora de se cuidar" no horário de Parauapebas

Para editar serviços e descrições: objeto `SERVICOS` em `script.js`. Sugestões do quiz: array `SINAIS`. WhatsApp: constante `WA`.
